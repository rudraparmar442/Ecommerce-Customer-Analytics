# Ecommerce Customer Analytics & Retention Intelligence Dashboard

## Project Overview

This project analyzes ecommerce customer behavior using:
- RFM Segmentation
- Cohort Retention Analysis
- Customer Lifetime Value (CLV)
- Revenue Trend Analysis

## Tech Stack

- Python
- Pandas
- DuckDB
- SQL
- Power BI
- Jupyter Notebook

## Dashboard Preview

![Dashboard](reports/dashboard_preview.png)

## Key Insights

- Champions generate majority revenue
- Repeat customers drive high CLV
- Revenue peaks during holiday season
- Retention drops after month 2
